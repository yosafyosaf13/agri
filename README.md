نظام ويب متكامل لإدارة العمل الميداني الزراعي — الزيارات،
المحاصيل، المعاملات، والتنبيهات — مع **مساعد ذكي صوتي** يفهم
بيانات المزرعة ويرد بالعربية باستخدام صورتين (Avatar):
- **الصورة 1 (حالة الاستماع):** تظهر عندما يستمع المساعد لك.
- **الصورة 2 (حالة الرد):** تظهر عندما يتحدث المساعد ويُسمع صوته.

A complete Next.js 16 web application for agricultural field-work
management — farm visits, crops, treatments, alerts — with a
voice-driven AI assistant that knows your live data and replies in
Arabic using two avatar states (listening / responding).

## 🛠️ البنية التقنية (Tech Stack)

- **Framework:** Next.js 16 (App Router) + React 19
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS 4 + shadcn/ui (New York) + Lucide icons
- **Fonts:** Cairo (Arabic) + Geist Mono
- **Animations:** Framer Motion
- **State:** Zustand (client) + TanStack Query (server)
- **Database:** SQLite via Prisma ORM (6 جداول)
- **AI:** `z-ai-web-dev-sdk` (LLM + ASR + TTS)

## 🚀 التشغيل (Getting Started)

### المتطلّبات
- Node.js 20+ / Bun
- منفذ 3000 متاح

### الخطوات
```bash
# 1) تثبيت الحزم
bun install

# 2) إعداد قاعدة البيانات (يُنشئ db/custom.db)
bun run db:push

# 3) بذر البيانات الأولية
bun run prisma/seed.ts

# 4) تشغيل خادم التطوير
bun run dev   # → http://localhost:3000
```

### بيانات الدخول الافتراضية
```
اسم المستخدم: admin
كلمة السر:    admin123
⚠️ غيّر كلمة السر فوراً من صفحة الإعدادات بعد أول دخول
```

### البيانات الأولية المبذورة
- مستخدم: `admin` (المهندس التجريبي، مسؤول)
- مزرعة 1: مزرعة النور التجريبية (سيد محمود، 2.5 فدان، شمال القرية)
- محصول 1: طماطم (سوبر استرين، 1.5 فدان، قائم)
- مزرعة 2: مزرعة الوادي الجنوبية (عائلة الأحمد، 5 فدان)
- محصول 2: بطاطس (سبونتا، 3 فدان، قائم)
- زيارة + معالجة رش (مانكوزيب) موعدها بعد 3 أيام → يظهر كتنبيه

## 🗄️ نموذج البيانات (Data Model)

```
User 1──N Farm 1──N Crop 1──N Treatment
                       │
User 1──N Visit 1──N VisitPhoto
Farm 1──N Visit ──┐
Crop 1──N Visit (SET NULL on crop delete)
Visit 1──N Treatment (SET NULL on visit delete)
```

| الجدول | الوصف |
|---|---|
| `User` | المهندسون (username, passwordHash, fullName, role) |
| `Farm` | المزارع (name, owner, area فدان, location) |
| `Crop` | المحاصيل (name, variety, plantingDate, area, status) |
| `Visit` | الزيارات (farmId, cropId?, visitDate, notes, aiResult?) |
| `VisitPhoto` | صور الزيارات (photoPath = filename في uploads/) |
| `Treatment` | المعاملات (type, product, dose, nextDate, done) |

## 🌐 مرجع الـ API

كل المسارات تحت `/api/*` وتتطلب مصادقة (كوكي الجلسة) وتُنسخ
البيانات حسب المستخدم الحالي.

### المصادقة
| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/auth/login` | `{username,password}` → جلسة |
| POST | `/api/auth/logout` | إنهاء الجلسة |
| GET | `/api/auth/me` | المستخدم الحالي |

### البيانات
| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/dashboard` | إحصائيات + تنبيهات + آخر الزيارات |
| GET/POST | `/api/farms` | قائمة/إنشاء مزرعة |
| GET/PUT/DELETE | `/api/farms/[id]` | مزرعة محددة (مع المحاصيل والزيارات) |
| POST | `/api/crops` | إنشاء محصول |
| PUT/DELETE | `/api/crops/[id]` | تعديل/حذف محصول |
| GET/POST | `/api/visits` | قائمة/إنشاء زيارة (مع صور base64 ومعالجات) |
| GET/PUT/DELETE | `/api/visits/[id]` | زيارة محددة |
| GET | `/api/search?q=` | بحث شامل |
| PUT | `/api/settings` | تعديل الاسم/كلمة السر |

### المساعد الذكي (Voice + AI)
| الطريقة | المسار | الدخل → الخرج |
|---|---|---|
| POST | `/api/ai/asr` | `{audio: base64}` → `{text}` (تحويل الكلام لنص) |
| POST | `/api/ai/chat` | `{message}` → `{reply}` (LLM + سياق البيانات الحية) |
| POST | `/api/ai/tts` | `{text}` → `audio/wav` (تحويل النص لصوت) |
| POST | `/api/ai/vision` | `{visitId, photoId}` → `{aiResult}` (تشخيص الصورة بالـ VLM) |

كل مسارات `/api/ai/*` تتحقق من الجلسة أولاً. مسار `/api/ai/chat`
يبني سياقاً من بيانات المستخدم الحية (عدد المزارع، زيارات اليوم،
التنبيهات، آخر الزيارات) ويضمنه في تعليمات النظام (system prompt).
مسار `/api/ai/vision` يقرأ الصورة من القرص، يحوّلها base64، ويرسلها
لنموذج الرؤية (VLM) مع سياق المحصول والمزرعة والملاحظات، ثم يخزّن
التشخيص في حقل `aiResult` بالزيارة.

### المعاملات
| الطريقة | المسار | الدخل → الخرج |
|---|---|---|
| PATCH | `/api/treatments/[id]/toggle` | `{done?: boolean}` → `{id, done}` (تبديل حالة الإكمال) |

### التقويم والتصدير
| الطريقة | المسار | الدخل → الخرج |
|---|---|---|
| GET | `/api/calendar?month=YYYY-MM` | معاملات + زيارات شهر محدد (للتقويم الشهري) |
| GET | `/api/reports` | تقرير شامل (إحصاءات + رسوم بيانية + جداول) |
| GET | `/api/export` | ملف JSON كامل (نسخة احتياطية لكل بيانات المستخدم) |

## 🤖 المساعد الذكي (AI Assistant)

### كيف يعمل
```
المستخدم يضغط الميكروفون
        │
        ▼
MediaRecorder (webm/opus) → base64
        │
        ▼
POST /api/ai/asr  ──→  نص (Transcript)        [Avatar 1: استماع]
        │
        ▼
POST /api/ai/chat  ──→  رد (Reply)            [Avatar: يفكر]
        │
        ▼
POST /api/ai/tts  ──→  WAV audio              [Avatar 2: رد]
        │
        ▼
<audio>.play()  ──→  عند الانتهاء → العودة للاستماع
```

### صورتا الأفتار (Avatars)
- `public/avatars/avatar-listening.png` — تظهر في حالتي:
  - **idle** (جاهز، في انتظارك)
  - **listening** (يستمع إليك أثناء التسجيل)
- `public/avatars/avatar-speaking.png` — تظهر في حالة:
  - **speaking** (يرد عليك ويُسمع صوته)

كل صورة 1024×1024، مولّدة بـ `z-ai image` بأسلوب نباتي زراعي.

### مثال أسئلة مجربة
- «كم زيارة اليوم؟»
- «ما التنبيهات القادمة؟»
- «أعطني نصيحة عن مكافحة اللفحة في الطماطم»
- «كم مزرعة عندي؟»
- «ما آخر زيارة؟»

## 🔒 الأمان

- ✅ كلمات السر بـ scrypt (كاشف أحادي الاتجاه، لا تُخزّن نصية)
- ✅ الجلسة في كوكي HttpOnly موقّع بـ HMAC-SHA256 (انتهاء 7 أيام)
- ✅ كل استعلامات Prisma مُعاملات (ضد SQL injection)
- ✅ كل مسارات الـ API تتطلب مصادقة وتُنسخ حسب المستخدم
- ✅ رفع الصور: تحقق من JPEG magic bytes (0xFF 0xD8) + حدّ 5MB
- ✅ ضغط الصور client-side (canvas 1280px JPEG q=0.85) قبل الرفع
- ⚠️ غيّر كلمة السر الافتراضية فوراً
- ⚠️ عيّن `AUTH_SECRET` و `DATABASE_URL` في الإنتاج

## 📦 النشر (Deployment)

### متغيرات البيئة (.env)
```env
DATABASE_URL=file:/path/to/db/custom.db
AUTH_SECRET=توليد-سري-عشوائي-32-حرف
NODE_ENV=production
```

### الخطوات
1. شغّل `bun run db:push` لإنشاء القاعدة
2. شغّل `bun run prisma/seed.ts` لإنشاء حساب admin
3. ابنِ بـ `bun run build` وانشر `.next/standalone`
4. (اختياري) بدّل `DATABASE_URL` إلى MySQL في الإنتاج الكبير
